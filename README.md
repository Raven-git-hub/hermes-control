# Hermes Control

GTK system tray application for controlling Hermes travel automation box.

## Requirements

- Ubuntu/Debian Linux
- Python 3
- GTK 3
- AppIndicator3

## Install dependencies

```bash
sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-appindicator3-0.1
```

## Run

```bash
python3 hermes-control.py
```

## Usage

1. Click the system tray icon
2. Enter Hermes IP address and click Connect
3. Control panel shows system stats and controls
